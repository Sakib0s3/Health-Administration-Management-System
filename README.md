# Health-Administration-Management-System

1. Project Overview
This project aims to develop a simple, databasedriven Health Administration
Management System to organize hospital services efficiently. It focuses on managing
staff, patients, departments, and appointment scheduling through a relational database.

2. Objectives
i. Build a relational database structure to handle hospital operations.
ii. Enable patients to search for doctors and schedule or cancel appointments.
iii. Maintain accurate records of departments, medical staff, and patient data.
iv. Track appointment statuses and generate realtime data views.

3. Core Features
i. Department Module: Stores unique departments with names and descriptions.
ii. Staff Module: Holds information such as doctor names, specializations, experience,
availability, and department links.
iii. Patient Module: Saves patient details including name, contact, and demographics.

iv. Appointment Module: Allows patients to book, view, and cancel appointments, with
time stamps and status updates.

4. System Design Highlights
ERD Model

5. Tools Used
XAMPP and phpMyAdmin for local development.
MySQL and SQL queries for database creation, data entry, and reporting.

6. Sample Functionalities
i. List all doctors in a specific department.
ii. Display available appointment slots for a doctor.
iii. View all patients born after a certain year.
iv. Track or cancel appointments.
v. Add new patient or staff entries.

7. Conclusion
This project demonstrates how structured database systems can improve hospital service
delivery by managing appointments, staff schedules, and patient access. It highlights the
practical use of ER modeling and SQL in solving realworld healthcare administration
challenges.
